# SpendSight

A lightweight, single-file expense tracker. No build step, no dependencies — data is stored in your browser (`localStorage`).

## Run locally
Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy on Vercel
1. Push this repo to GitHub.
2. Go to https://vercel.com/new and import the repository.
3. Framework Preset: **Other**. Leave Build Command and Output Directory empty.
4. Click **Deploy**.

Or via CLI:

```bash
npm i -g vercel
vercel --prod
```
